## Discrepancy log (early development claims vs current artifact truth)

This log reconciles figures from earlier development notes against the
numbers the current code actually produces. It exists so that any older
claim a reader might encounter can be traced to why the shipped figure
differs. The retired early figures themselves are not published anywhere in
the case study; only the current, reproducible numbers are.

1. **An earlier shipped variant** (35% vol target, 1× gross, top-1
   selection) produced different headline figures. It was replaced for two
   reasons: top-3 basket selection (the top-1 variant was tie-break-fragile
   — its yearly total moved by double-digit points from nothing more than a
   change in how exact score ties break, which is *why* it was replaced) and
   the risk dial (vol target 0.50, 1.5× cap). The old top-1 figures are not
   exactly reproducible by current code and are **not** published as
   results; the closest current analogue is the unleveraged reference
   (+30.2%/+37.4%/+12.6%).
2. **Early top-1 frozen-replay claims for 2024/2025.** Same provenance
   (top-1, unleveraged). Current artifact replays: 2025 +54.5% / 2024
   +16.5% (dialed) or +37.4% / +12.6% (unleveraged reference).
3. **"1h and daily bars: 4h dominated."** Confirmed for daily bars (large
   negative deltas everywhere). For 1h bars the fresh recompute is mixed
   (−8.6pp 2024, +6.5pp 2025, −1.4pp 2026): at current settings 1h is
   *not consistently worse*, it is roughly comparable with more churn. The
   README states the weaker, accurate version.
4. **Early "kill switch turned +32% into −19% (2025)" note.** Directionally
   confirmed; the current numbers for that variant are +41.0% → −12.6%
   (values shift with the selection code's tie-breaking). README uses the
   current numbers.
5. **Early "emergency refits made 2026 worse" note.** Same effect at the
   current baseline: +45.1% → +23.0% (−22.1pp). README uses the fresh
   numbers.
6. **"F&G + positioning made all three years worse."** At the current
   (top-3, dialed) baseline the recompute shows 2 of 3 years materially
   worse and 2026 slightly better — still rejected (fails the
   all-years bar), but the README states it precisely.
7. **Early "max 1× gross, no leverage" claim.** Outdated: the shipped
   configuration uses a 1.5× position cap since 2026-06-12. The README
   describes the current sizing and shows the unleveraged reference.
